# baby-log

小月亮 · 母婴记录。纯静态网页，无构建步骤，直接托管在 GitHub Pages。界面支持简体中文、繁體中文、English（设置里切换，按设备保存）。

## 文件结构

## 头部、「我的」与打印

- 标题旁的 ‹ 小助手 / 学堂 › 徽章切到上一个 / 下一个姐妹站点；头部右侧只有同步状态。
- 「成长」和「妈妈」也是入口列表：成长页顶部保留阶段条，下面六行（里程碑 / 新食物 / 睡眠 / 体重身高 / 体检与就诊 / 疫苗）各进子页；妈妈页保留记录按钮和用药计时，曲线和警示信号进子页。子页的 tab 键形如 `grow-sleep`、`mom-charts`，在 `views.js` 的 `SUB` 表里登记父页签。
- 「今天」是仪表盘，不拆分：顺序为计时 → 红色警示与体检提醒 → 快捷按钮 → 24 小时统计 → 妈妈用药 → 当天记录。从今天页保存一条记录后自动滚到「今天」区并高亮新记录 3 秒。
- 子页顶部是完整的面包屑路径（和 home-pantry 同一设计，`views.js` 的 `crumbHTML`）：`‹ 我的 / 家庭 / 家庭协作`，前面每一级都可点，最后一级加粗；`SUB` 表登记每个子页的父页，`PAGE_LABEL` 登记标题；滚动后的迷你栏里也显示同一条路径。
- 底部第五个页签「我的」是入口列表（和 homeschool 同一设计，`js/me.js`），七行各带图标和一句实时摘要：小Y问 / 家庭 / 同步、备份与恢复 / 语言、单位和显示 / 卡片 / 问答 / 介绍；下面是四个打印项和姐妹应用。
  - 「家庭」是第三层目录：顶上一张摘要卡（家庭名、成员、孩子），下面四行各进自己的页：家庭协作（登录、邀请码、成员管理，`sync.js` 的 `familyHTML`）、孩子、妈妈用药间隔、信仰（可选）。这些设置属于整个家庭，保存后回到「家庭」目录。tab 键 `family`、`family-members` 等，`SUB` 表支持多层父页（`render()` 一路找到底部页签）。
  - 「同步、备份与恢复」见下一节。「语言、单位和显示」只影响本机。旧的 `settings` 键仍指向「家庭」目录。

## 小Y问（`js/ask.js`、`js/ai.js`）

- 入口：我的 → 小Y问；今天页快捷按钮下方的「小Y问」chip；问答页里的「去小Y问」。和爱家小助手的「小Y问」同一套思路。
- 场景按孩子的阶段显示，每个是一句可改的默认问题：下次喂奶、尿布与消化（新生儿 / 婴儿）、睡眠与作息、辅食与吃饭（婴儿到学前）、情绪管理（幼儿起）、陪伴与互动、生长发育、妈妈产后恢复（新生儿期）、要不要看医生。
- 「附带记录摘要」默认勾上：最近 7 天的统计（喂奶次数 / 间隔 / 奶量、睡眠时长与段数、尿布、饮食与新食物、情绪行为种类、陪伴与活动时长、如厕、语言、最近体重身长、里程碑、体温；新生儿期加妈妈身体与用药），全是数字和固定选项值，不含备注、起因、谁陪的、孩子姓名。页面底部「会发送什么」能看原文。
- 有 key：浏览器直连模型，答案在页内显示（简单 markdown 渲染，可复制）。没 key：「复制提示词」把系统提示 + 摘要 + 问题拼好，并列出 ChatGPT / DeepSeek / Claude / 豆包 / 通义千问 / Kimi / Gemini 的链接。
- API key 在页内「填 API key / 换模型」里设置（服务商、key、模型、自定义接口地址、测试连接），只存本机 localStorage，不同步；爱家小助手里填过的 key 自动沿用。

## 同步、备份与恢复（`js/backup.js`）

- 一页四块：同步状态卡（家庭同步 / 待同步 / 登录失效 / 仅本机，带「立即同步」或「加入家庭」）→ 备份 → 已有的备份 → 从文件恢复；导出 CSV、演示数据、清空全部折叠在最下面的「数据工具」里。
- 备份 = 这台设备上的 settings + entries（不含演示数据）。目的地是一格一格的卡片（手机一列，≥600px 两列），可多选：家庭云端（Supabase Storage `backups` 桶，迁移 017）、Google Drive、Dropbox、这台电脑的文件夹（File System Access，桌面 Chrome / Edge）、下载。云端 / 云盘 / 文件夹只留 60 天。定时按周 / 按月 / 自定义天数，到期后下次打开应用时在后台做一次。
- iCloud Drive / OneDrive 没有网页接口：电脑上把「文件夹」选成它们同步的文件夹；iPhone 上用「下载」再分享到「文件」存进 iCloud Drive。
- **云盘备份**（详细步骤见 [docs/backup-and-sync.md](docs/backup-and-sync.md)）要在 `js/config.js` 填两个公开的客户端标识（不是密钥，和 anon key 一样可以放在网页里），留空时卡片显示「需要先在 js/config.js 里填好」：
  - Google Drive：Google Cloud Console → APIs & Services → 启用 Google Drive API → OAuth 2.0 客户端（类型 Web 应用），「已获授权的 JavaScript 来源」填站点地址（如 `https://dev-hyang.github.io`，本地调试再加 `http://127.0.0.1:8765`），把客户端 ID 填进 `GOOGLE_CLIENT_ID`。权限只要 `drive.file`（只能看到应用自己建的文件），备份放在「小月亮备份」文件夹。令牌一小时过期，续期要用户点一下，所以定时备份到期时会出现「继续备份」。
  - Dropbox：Dropbox App Console → Create app → Scoped access，Access type 选 **App folder**，Permissions 勾 `files.content.write` / `files.content.read` / `account_info.read`，Redirect URIs 填站点地址（带结尾 `/`），把 App key 填进 `DROPBOX_APP_KEY`。用 OAuth 2 PKCE 拿 refresh token，定时备份可静默续期。
  - 令牌存在本机 localStorage；「断开」会吊销并清掉。
  - 备份放在设置里填的路径下：Google Drive 默认文件夹「小月亮备份」（可改成「备份/小月亮」这类多级路径，不存在就逐级建）；Dropbox 是应用文件夹（Apps/<应用名>/）里的子路径（留空 = 直接放应用文件夹）。不往云盘根目录随便放。代码在 `js/cloud-drives.js`，四个应用共用同一份。
- 恢复 = 把备份里的记录合并进来（已有同 id 的不动，缺的补上；设置合并），家庭模式下同步给全家。老版本「导出备份」的文件也能恢复。
- 打印四种页面：按餐表格（记录页当前显示的那一天，横版）、趋势对比（按天最近 7 天 / 按周最近 8 周，横版）、时间线（当前筛选和搜索，最近 30 天）、就医记录（体检与就诊、体检时间表、疫苗、生长测量、最近 90 天宝宝用药）。黑白表格，不依赖主题色。

## 多语言

- 代码里的界面文字一律写简体中文并包在 `t("…")` 里；带变量用 `t("已保存 {n} 条", { n })`。简体中文不需要字典，`en.js` / `zh-TW.js` 以原文为 key。
- 记录里的选项值（喂奶方式、大便颜色、如厕地点……）始终按简体中文原文保存，只在显示时翻译，所以家人各用各的语言看到的是同一份数据。自由文本（备注、食物名、疫苗名）按用户输入保存，不翻译。
- 语言是本设备设置（`xiaoyueliang.v1.lang`：auto / zh-CN / zh-TW / en）。已有数据的老安装默认保持简体中文；新安装按浏览器语言。
- 新增文字后可用脚本检查字典是否漏项：提取所有含中文的双引号字面量，与两份字典比对（见 i18n.js 顶部说明）。

## 家庭协作与账号

- 创建家庭的人用邮箱注册（Supabase 邮箱确认），成为 **家主**；邮箱只用来在新设备上找回家庭。
- 其他家人不用注册：在设置里输入邀请码即可加入。实现上是 Supabase 匿名登录（需在后台打开 Allow anonymous sign-ins）+ `join_family()`，身份绑定在这台设备上；清理浏览器数据后再输一次邀请码即可。
- 家主可以重置邀请码、修改任何成员的称呼、把家人设为家主 / 转回成员、移出成员；成员可以改自己的称呼。服务器端由 `supabase/migrations/009_*.sql`、`010_*.sql` 里的 `is_owner()` 和各 RPC 校验，家庭至少保留一位家主，匿名用户不能创建家庭。被移出的设备在下次同步时自动退出家庭并清除本机副本。

## 记录可见性（迁移 012）

每条记录有三档可见性：**仅我**（只有记录者）、**指定家人**（记录者加上选中的成员，对方只能看不能改）、**全家**（默认，和以前一样）。记录表单底部的「谁能看到」只在家庭模式且已运行迁移时出现；情绪 / 自律 / 社交默认「仅我」，其余默认全家，并记住本设备上每种记录最近一次的选择。

- **服务器端强制**：`supabase/migrations/012_entry_visibility.sql` 给 `entries` 加 `visibility`、`shared_with`，把原来的 `ent_all` 换成按可见性的 select / insert / update / delete 策略（用已有的 `created_by`）；非全家记录只有记录者能改能删，`created_by` 由触发器锁定。家主也读不到别人的私密记录。已有记录回填为全家。
- **客户端**（`sync.js`）：`toRow` / `applyRow` 在记录上用 `vis`（非全家才有）、`with`、`cby`（记录者）；迁移没跑时用一次 `select visibility` 探测，探测失败就不发这两列、不显示控件，行为和以前一样。分享给你的记录用只读面板打开。
- **收回可见性的传播**：服务器只是不再返回那条记录，别的设备本地缓存里还留着。`reconcile()` 在进入家庭、点「立即同步」和每 5 分钟（同步时）对比服务器仍给本成员看的 id，清掉多余的缓存（候选 id 会按 id 再确认一次）。所以「全家 → 仅我」在其他设备上最多几分钟后才消失。
- **限制**：这是行级权限，不是端到端加密，能进 Supabase 后台的人仍能读到内容；用邀请码加入的设备是匿名身份，换手机后是新身份，原来「仅我 / 指定家人」的记录要用创建时的账号才能找回；统计和打印只含当前成员能看到的记录。

## 信仰模块（可选，默认关闭）

家庭自己决定要不要。「设置 → 信仰（可选）」里打开后才出现；关闭时 App 里看不到任何信仰相关的内容（快捷卡片、统计、趋势指标、补记类型都不出现），已写的记录仍保留在记录页，时间线的「信仰」筛选在有记录时照常出现。

- 设置在家庭级：`settings.faith = { on, statement, off: [不显示的孩子 id] }`，随 `families.settings` 同步。信仰宣告是家庭自己的话（可用模板「我们是一个基督徒家庭，愿意带孩子认识神、爱神、爱人，从小学做荣神益人的小门徒。」），所有家人都能看到，显示在信仰记录表单顶部。
- 记录类型 `faith`：家庭敬拜 / 祷告（可勾已蒙应允）/ 读经 / 背经 / 服事 / 主日聚会 / 感恩 / 个人灵修，时长、和谁一起、内容、备注；可一次记给几个孩子。快捷卡片：祷告、读经（幼儿起）、家庭敬拜、服事（学龄起），统计「敬拜 / 祷告」，趋势指标「信仰记录」。
- 可见性沿用上一节：青少年阶段默认「仅我」，其余默认全家。
- 原则：只记录家庭一起做了什么，不给孩子的信心打分，不做连续打卡、排名或红色警示。计划和经文卡片由 homeschool 站点负责，这里只做轻量记录，不重复做计划。
- 实现：`stages.js` 的 `faithOn()` / `withoutFaith()` 在卡片、统计、指标、类型四处统一过滤。

## 成长阶段

按孩子的生日自动判断阶段（新生儿 0–3 月、婴儿 3–12 月、幼儿 1–3 岁、学前 3–5 岁、学龄 6–11 岁、青少年 12 岁起），首页快捷按钮、统计卡、趋势指标、时间线筛选、成长页参考内容随阶段变化。学龄和青少年阶段不再默认显示吃饭、如厕、尿布，改为陪伴、情绪、自律、社交。

**卡片可按孩子自定义**：快捷按钮和 24 小时统计（含顶部大计时 `hero`）都是「卡片」。「我的 → 卡片」（或今天页的「管理卡片」）里每个孩子可以关闭阶段默认的卡片，也可以从其他阶段加回来。只存与阶段默认值的差异：`settings.cardPrefs[孩子id][quick|stats] = { on: [...], off: [...] }`（`stages.js` 的 `activeCards` / `setCard`），随 `families.settings` 同步。关闭卡片只影响今天页；记录、时间线筛选（有记录的类型始终出现）和趋势对比里的历史都不受影响，随时可以重新打开，「恢复默认」清除该孩子的差异。

记录类型：

- 全阶段：喂奶、尿布、睡眠、宝宝健康（来源：自己记录 / 儿科体检 / 看病急诊）、宝宝用药、疫苗接种、里程碑
- 成长页「儿科体检与就诊」可在提醒（Bright Futures 时间表）和历史记录之间切换；保存一条儿科体检记录会自动勾选三周内对应的提醒
- 婴儿期起：饮食（辅食 / 三餐，含新食物与过敏反应）
- 幼儿期起：如厕、语言、活动（阅读 / 户外 / 幼儿园 / 屏幕…）、情绪行为
- 学龄期起：陪伴（谈心 / 游戏 / 运动 / 外出，谁陪的、多久；可一次记给几个孩子）、情绪（1–5 心情、状态、起因、怎么调整；1 分会提示联系可信任的人）、自律（作息 / 作业 / 运动 / 屏幕 / 家务 / 节制，可勾「自己做到」）、社交。情绪、自律、社交默认「仅我」可见，陪伴默认全家可见（见下一节「记录可见性」）
- 妈妈用药、妈妈身体属于家庭，不随孩子切换；妈妈页在新生儿期或最近 30 天有妈妈记录时显示

ES Module 需要通过 http(s) 访问；直接双击 `index.html` 以 `file://` 打开时浏览器会拒绝加载模块，本地调试请起一个静态服务，例如 `python -m http.server`。
